彩虹蛋蛋

How To Play

怎么玩？

🥚
  1. 从 7 只蛋蛋里选一只你最喜欢的颜色（粉 / 蓝 / 绿 / 黄 / 红 / 灰 / 紫）。
  2. 点「出发！」游戏开始，草地上会出现彩虹糖 🍬。
  3. 用方向键 / WASD 控制，手机上用下面的方向按钮，跑过去碰糖就吃掉。
  4. 吃掉一颗马上会出现下一颗，30 秒内收集越多越厉害！
  5. 时间到显示成绩，最高纪录会保存，换蛋蛋再战！
  6. 💡 小秘诀：别来回跑冤枉路，眼睛先看下一颗糖在哪，抄近路直线冲过去！电脑上用 WASD 比方向键更快哦。
